# Disease_Diagnosis_chatbot
An AI-powered Disease Prediction Chatbot that uses NLP, TF-IDF vectorization, and a CNN deep learning model to predict possible diseases based on user symptoms. Developed using Python, Django, and MySQL, with email notifications and doctor appointment booking features.


# AI-Based Disease Prediction Chatbot

An AI-powered chatbot that predicts possible diseases based on user-provided symptoms using Natural Language Processing (NLP) and a CNN Deep Learning model.

## Technologies Used

- Python
- Django
- HTML, CSS, JavaScript
- MySQL
- CNN (Deep Learning)
- TF-IDF Vectorization
- NLTK

## Features

- User Registration and Login
- Symptom-Based Disease Prediction
- AI Chatbot
- Disease Information and Diet Recommendations
- Doctor Appointment Booking
- Email Notifications
- Prediction History

## How It Works

1. Users enter their symptoms through the chatbot.
2. NLP techniques clean and preprocess the input text.
3. TF-IDF converts symptoms into numerical features.
4. The CNN model predicts the possible disease.
5. The system displays disease information and diet recommendations.

## Database

MySQL is used to store:
- User Details
- Disease Prediction Results
- Doctor Appointment Details

## Disclaimer

This project is developed for educational purposes. Predictions are not a substitute for professional medical diagnosis or treatment.
